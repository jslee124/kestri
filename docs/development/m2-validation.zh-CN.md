## 真实任务与重启

在主人明确授权下，一项临时每日任务请求从 LangChain 官方公开材料生成三句话简报，带来源及明确的 `Asia/Shanghai` 时区。真实 DeepSeek 官方 API 创建约定，Telegram 回显。通过真实主人消息暂停、修改时间和恢复，达到 active 第 4 版，计划本地时间 20:43。

应用于 UTC 12:40:25 停止，在 UTC 12:43:00 到期之后重启。UTC 12:43:33 只启动一项后台执行，使用保存的第 4 版约定。该执行使用新图上下文，真实调用 DeepSeek/Tavily，保存 completed 结果，并通过 Telegram 发送一次。执行期间 `/tasks` 正常响应。简报包含三句正文、来源和获取/截断限制。来源状态附录比理想情况长，简洁展示仍待产品改进；本次验证没有独立核实生成的新闻事实。

投递后立即通过主人消息删除任务，留下第 5 版 `deleted` 状态。`/tasks` 显示没有任务。数据库确认总共一项后台执行、零未删除任务及零排队/运行后台执行。随后真实回复已完成简报，区分成功提取、失败提取和仅搜索摘要的材料，没有再次获取网页。删除任务保留这些归档记录。

五次任务控制与一次调度执行的本地估算为 $0.067842；证据追问增加 $0.004317。验证总估算 $0.072159，低于授权上限 $0.50。这些是配置的本地估算，不是服务商账单。[脱敏真实元数据](evidence/m2-live.json)保留执行标识、时间、状态、用量和投递状态，不包含凭据、主人/聊天 ID、完整消息、推理或来源正文。Telegram 原生菜单实际列出全部九个命令，包括 `/runs`、`/tasks` 和 `/task`。
