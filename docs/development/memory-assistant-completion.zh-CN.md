# 对话式记忆交付

[English](memory-assistant-completion.md) · [使用参考](../reference/memory-assistant.zh-CN.md)

更新：2026-10-02。本次范围已实现，真实验收和部署记录如下。

## 实现

自然语言查看/设置、多个独立开关、共享记忆修改服务、有界首页/分页/详情、主人专属只读导航与歧义选择按钮、跨重启数字选择、真实调用记忆诊断均已实现。模型提案与事务执行分离，复用授权、费用和幂等机制。普通回答保持纯文本，控制结果采用转义 HTML 和主人时区。一次发送多条命令只提示拆分，不执行。

迁移 10 增加选择和展示字段；逻辑备份 schema 8 接受旧 schema 4–7。逻辑恢复清空选择/展示/诊断，不重放写入。诊断不保存查询或正文副本，展示时重验当前事实和授权。

## 验证

pgvector 全量 280 项通过；普通 PostgreSQL 252 项通过、28 项向量测试按条件跳过。Ruff 检查/格式、57 个模块 mypy、10 个 SQL 迁移可读性、双语文档链接检查均通过；wheel/sdist 构建通过。集成测试使用真实 LangChain 结构化提案和图中间件，覆盖身份、提案授权、错误回执、重复/重启、目标版本/代次、遗忘诊断和旧备份恢复。

独立数据库和工作区通过已登录 Chrome 对同一个 Telegram bot 做合成验收，仅复制轮询 offset：一句话开启 auto/semantic、自然保存两条相似事实、歧义时无修改、重启后按钮选择并遗忘、剩余事实经真实混合检索参与回答、依据按钮显示实际注入、自然暂停使用后旧诊断不再展示正文、只读设置导航。最后停止独立轮询器并协调 offset，合成记忆未导入正式数据库。

## 部署与边界

正式库迁移 9→10，启动前保留 27 次执行、133 条消息，原数据库/工作区卷不变。迁移前 raw dump 在独立库恢复通过；四张 checkpoint 表计数一致：10/161/111/251。主人本次自行开启的 auto/use/semantic 全部保留。迁移后 schema 8 私有逻辑备份保留在忽略目录，迁移前应用镜像保留为回退标签。回退应恢复到独立卷，不直接复用升级后的数据。

这些证据覆盖本次合成流程及部署完整性，不代表所有自然语言表达、长期个人化质量、全部平台或真实断电恢复都已验证。词项入口采用保守识别；不支持的表达可能需要澄清或命令。历史选择范围与召回覆盖继续沿用已有参考中的限制。
