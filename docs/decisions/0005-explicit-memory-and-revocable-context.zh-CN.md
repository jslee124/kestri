# ADR-0005：显式记忆与可撤销对话上下文

[English](0005-explicit-memory-and-revocable-context.md) · [文档](../README.zh-CN.md)

日期：2026-10-01。状态：M3 已接受。

## 背景

个人记忆需跨重启持久化，又不能成为授权通道。忘记需要消除图状态和摘要中的缓存影响，同时原始记录可独立查看。Kestri 已分离主人控制、PostgreSQL 业务记录、研究工具和 LangGraph checkpoint。

## 决策

使用确定性的显式主人记忆指令，PostgreSQL 行包含范围、来源、状态、替代关系、到期和按执行标识保存的回执。不从归档或模型推断提取记忆。先采用结构化/关键词检索、有上限的条目数和临时模型请求注入。研究和摘要没有记忆写入或任务管理能力。

记忆变更或到期时递增主人上下文版本，重置已提交前台指针。旧版本结果/证据不再自动进入上下文，新计费工作和前台指针提交前检查版本。保留删除标记和历史，供显式查看。这种较广失效比尝试移除旧摘要中所有语义改写更简单。

采用锁定版本 LangChain 摘要中间件的安全切点行为，扩展摘要请求以保留 Kestri 费用准入、取消、输入/输出上限和有限尝试。原始消息保留在已有归档中。摘要是非可信历史数据，权限、任务约定和记忆在摘要之外。

## 备选方案

向量存储和自动推断会在需求尚未证明前增加检索/同意复杂度。模型记忆工具扩大来源注入边界。精确删除摘要片段可能漏掉改写，基于完整历史重建可能重新提取已忘记事实。无限增长的主对话会使费用和准入不可预测。这些方式暂缓。

## 影响与复审

记忆变更重置当前对话连续性，旧自动回复引用可能不可用。显式 `/history` 保持可用，不进入模型。忘记表示移出活跃使用，不是所有本地/外部副本的物理擦除。在途外部请求无法撤回。备份恢复需在检索前核对删除标记，仍属 M4。

摘要质量取决于模型。无法在预算内安全压缩时停止，并提示新建上下文。保护摘要方法扩展依赖 lockfile 和回归测试，升级框架需复核。只有更细粒度失效可靠防复活的证据充分时，才调整版本粒度。

一手来源核对于 2026-10-01：[LangChain 摘要中间件](https://docs.langchain.com/oss/python/langchain/middleware/built-in#summarization)。应用同意、版本及删除边界属于 Kestri 决策。
