# ADR-0007：自动与语义个人记忆

[English](0007-automatic-semantic-memory.md) · [文档](../README.zh-CN.md)

日期：2026-10-02。状态：方向已接受；embedding 接入与持久化自动提取已在功能分支实现；语义召回与真实验收待完成。

## 背景

仅显式写入与关键词召回不足以满足日常个人助手体验。主人不应反复输入记住指令或相同措辞。现有来源归档、记忆状态、事务回执与代次撤销提供基础。

## 决策

采用 [Memory v2](../design/memory-v2.zh-CN.md)：整体开启后自动提取主人直接陈述、隔离推断候选、带来源归并、时效状态、语义与关键词召回、有界原始历史工具。选择北京 DashScope `text-embedding-v4`、1024 维，先实现独立校验适配器，后续在现有 PostgreSQL 用 pgvector 存派生向量。应用校验模型提案，记忆不能授权任务或外部动作。

在对应 Memory v2 增量**实现并验收后**，替代 [ADR-0005](0005-explicit-memory-and-revocable-context.zh-CN.md) 的仅显式/无向量方向。此之前 ADR-0005 仍描述运行产品。保留来源/状态分离、临时注入与保守撤销。新增/强化将不重置 head，替代/忘记/到期继续使 epoch 失效。首版忘记采用较广自动历史截止位置，不承诺语义精确删除全部改写。

## 备选方案

只加 embedding 无法学习值得记住的事实；只自动写入无法召回改写。个人初始规模下独立向量数据库增加不必要存储边界。在当前 512 MiB 应用容器中运行下载模型需额外资源工作，暂缓本地推理，保留适配器边界。精细语义墓碑不足以作为首版可靠防复活保证。

## 影响与复审

个性化增强同时提供整体开启与查看/纠正/忘记控制。自动使用前需实现后台作业、并发、预算、来源、备份版本与清理。服务商输入会离开本机，本地模型可作为后续替代。较广历史截止位置牺牲无关旧历史召回，需在回执中说明。独立 smoke 不等于记忆质量评测或向量数据库验收。见[接入参考](../reference/embedding.zh-CN.md)与[证据](../development/embedding-validation.zh-CN.md)。

当前实现边界与调整见[进度](../development/memory-v2-progress.zh-CN.md)；已部署 M0–M4 验收仍是历史证据，不代表自动记忆验收。
