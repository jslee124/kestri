# 统一助理控制

[English](assistant-controls.md) · [文档](../README.zh-CN.md)

2026-10-02：已批准实施。自然语言、命令和按钮共用业务服务；不开放任意命令或配置执行。

## 交互

统一识别任务、记忆和运行控制。支持“我有哪些任务”“暂停每天的新闻简报”“现在在做什么”“停止当前执行”“开始新话题”和帮助/用量查看。只读查询走确定性路径，无模型调用。引用、否定、假设和转发不能授权写入；多项不兼容控制要求分开说明。

任务目标不唯一时最多显示五个候选，支持数字回复和选择按钮。缺少时间等信息时可补充明确片段；普通聊天不会自动填入控制。选择/补充绑定原始主人消息、操作、目标版本、代次及十分钟期限，跨重启有效，提交前重新验证，成功后消费。设置重置、开始新话题、清理和恢复撤销选择。

## 展示与实现

共享入口负责路由，任务/记忆服务负责权限与事务。任务列表摘要分页，详情展示本地时间、状态和内容；运行状态、用量、帮助和失败采用统一的转义 HTML 与只读导航。写操作按钮只允许已发出的短期选择，导航不直接切换设置或删除任务。

复用已有持久选择字段，带 domain 区分任务与记忆，避免新增重复存储。逻辑恢复清空选择，不恢复授权。保留原始请求，补充只使用同一主人直接消息的有界链条；模型提案不能制造来源。

## 验收

覆盖口语、指代、否定、混合请求、陈旧/到期选择、重复点击、连续时间修改和重启。评测分别统计路由、误操作和澄清后完成，不用模拟模型结果证明真实语言理解。执行两种数据库、格式/类型/SQL/文档/打包检查；隔离 Telegram 合成实测后备份、部署、重启、提交推送并核对准确提交 CI。长期个人化继续另行观察。
