更新日期：2026-10-01。状态：设计草案；策略方向已确认。下方完整控制仍是第一版要求。[M1 证据](../development/m1-validation.zh-CN.md)记录研究边界和容器检查；M2 已实现持续调度，M3 已实现显式记忆/上下文控制。保留期执行与备份恢复属于 M4。当前行为见 [Telegram](../reference/telegram.zh-CN.md)、[任务](../reference/tasks.zh-CN.md)与[记忆/上下文](../reference/memory-and-context.zh-CN.md)参考。

## 目标与信任边界

保护用户现有文件、凭据、个人数据和对委托工作的控制，让权限与数据用途易于理解，限制错误、恶意来源内容和意外高费用或长时间执行造成的影响。

用户和明确配置的应用策略授权操作。模型提出工具调用，应用代码判断是否执行。网页、提取内容、工具输出、生成摘要与推断偏好都不能授予权限。

| 边界 | 第一版策略 |
| --- | --- |
| Telegram 身份 | 只允许配置好的用户 ID 和私聊 |
| 可信应用 | 持有凭据，负责授权、调度、记忆与持久状态 |
| 模型 | 接收选定上下文和允许的工具定义，不直接访问本机或数据库 |
| 受控工具 | 验证参数与范围，只执行有边界、获允许的操作 |
| 工作区 | 按任务和执行分隔的专用研究与成果文件 |
| 未来代码沙箱 | 独立执行环境，在加入脚本或代码执行时再实现 |

“可信应用”描述软件边界，不保证全部代码正确。初始工具共享应用进程权限，并不是独立隔离的沙箱。不开放模型生成代码的任意执行，使权限仍由受控操作封装。

## 本地部署与文件访问

通过 Docker Compose 在本地运行应用与 PostgreSQL。应用使用非 root 用户、最少 capabilities、默认 seccomp、资源限制和必要挂载。数据库位于内部服务网络，不公开数据库端口。不把 Docker daemon socket 挂载给应用。

M1 默认使用专用命名工作区卷和独立数据库卷，不暴露现有宿主机用户目录。后续可将专用本机目录绑定挂载为工作区。可写绑定会修改真实本机文件，包括删除，并非临时副本。Docker 文档说明了这种行为，并支持只读挂载。Docker Desktop 自身在 Linux VM 中运行 daemon，但绑定的本机文件仍然暴露。见 [Docker 绑定挂载](https://docs.docker.com/engine/storage/bind-mounts/)和 [Engine 安全](https://docs.docker.com/engine/security/)。

工作区操作必须检查解析后的路径，拒绝目录穿越和符号链接逃逸，并限定于当前任务和执行范围。不得悄然覆盖或删除重要原件。用户原件应通过后续显式导入设计，以副本或只读方式访问。广泛访问 home 目录不属于第一版。

数据库数据、凭据和备份位于模型可见工作区之外。同一可写工作区中的备份不构成独立恢复边界。M1 的卷和路径选择见其参考；备份机制仍待确定。

加入任意代码时，使用独立短生命周期工具容器，只提供任务输入和输出。不提供个人数据库、服务凭据、本机控制 socket 或无关文件。文件处理任务默认无网络，限制进程、时间、输出和资源。更重的不可信执行可以重新评估 VM 隔离。本基线尚未选择沙箱管理组件及其实现。

## 工具授权与影响

工具操作前，检查用户身份、有效执行、授权范围、参数格式、路径或 URL、取消状态和资源限制。工具定义本身不构成强制限制。

明确的任务创建和记忆写入，在目标清楚时执行并准确回执，不重复要求批准。有歧义的修改或删除先澄清。现有用户授权只在保存的范围内有效。

允许在专用任务工作区内生成成果。第一版不暴露重要原件访问、已连接账号变更、任意 shell、插件或电脑控制。以后任何确认都必须绑定具体操作和参数；模型生成的“已批准”声明没有授权效力。

## 网页访问与不可信内容

公开信息访问通过受控搜索和提取适配器完成，限制时间、本地获取时的重定向、响应大小和模型可见输出。只接受支持的公开网页 URL，拒绝 localhost、私有及链路本地地址、元数据接口、内嵌凭据和不支持的协议。本地获取必须验证解析后的目标和每次重定向，不能只检查初始字符串。

服务侧提取也需要明确的公开 URL 策略。不能假定把 URL 交给 Tavily 就替代了 Kestri 的策略，或保证了服务侧目标地址限制。必须测试选定适配器的行为；未来本地获取工具需要独立强制网络检查。

保存来源 URL、获取时间、可用发布时间和截断或失败状态。必要时单独保存完整材料，向模型提供有边界的片段或引用。来源内容即使经过摘要仍然是证据，其中的指令不是用户请求。

## 个人记忆

将个人记忆与对话归档、执行状态、任务约定和研究证据分开。检索从结构化、关键词访问开始，只提供少量适用偏好和任务相关记录。在证明存在检索需求前，暂不加入向量搜索。

每条记录保存内容、来源消息、范围、创建与修改时间，以及有效、已取代或已忘记状态。显式写入回显保存内容。推断偏好在获得同意前只作为建议。任务偏好不自动变成全局偏好。临时事实可以过期，有冲突的纠正取代旧记录。

敏感事实需要明确保留意图。凭据属于专用密钥配置，不能写入个人记忆。记忆不能授权文件访问、账号操作或持续工作。

忘记后，从活跃检索中移除记录，并禁止从保留来源消息中自动重新提取。包含该记录的上下文缓存和摘要需要失效或重新生成。历史副本不得悄然重新进入自动上下文；显式查看归档是独立操作。用户未来的明确请求可以建立新记忆。声称删除有效前，必须设计删除标记和恢复处理。

M3 已实现删除标记、过期筛选与上下文代次失效：每次成功记忆变更重置前台指针，阻止自动访问旧回复/证据。显式归档查看仍可用。这是退出活跃使用，历史副本未物理擦除。尚未实现恢复核对，见[记忆/上下文参考](../reference/memory-and-context.zh-CN.md)。

## 对话上下文

一个 Telegram 聊天同时包含主对话与后台结果，内部使用不同上下文。组装近期完整交互、较早历史的滚动摘要、相关记忆和选定任务证据。回复关联支持准确检索过去的任务结果。

压缩前单独保存原始消息。LangGraph 检查点追踪执行状态，可以包含摘要，不是原始归档的权威来源。裁剪时保留完整工具调用与结果交互。摘要保留目标、决定、约束、纠正、未完成工作和来源或成果引用，不将不可信文本升级为指令。

权限、任务生命周期和授权保存在摘要之外的结构化记录中。压缩不创建个人记忆。摘要不足时检索仍保留的原件或证据；材料过期则说明缺口。

活跃请求预算和触发点统一维护在[架构](architecture.zh-CN.md)文档中。Token 统计必须包括提示词和工具开销，并为输出留空间。自动摘要失败需要有边界的恢复，不得编造摘要或发出无限膨胀的超限请求。

## 数据处理与密钥

本地存储不代表全部处理都在本地。选定服务接收完成其职责所需的数据：

| 服务 | 跨越边界的数据 |
| --- | --- |
| Telegram | 对话消息、状态更新和发送成果 |
| DeepSeek 官方 API | 组装后的提示词、选定记忆、对话材料、工具定义和相关工具结果 |
| Tavily | 搜索查询和提取 URL；获取的材料返回 Kestri |
| Cloudflare，仅在显式 DNS 模式下 | 核验候选公开网页域名，不发送服务凭据 |

只发送相关数据，不发送全部归档或数据库。服务凭据只提供给其应用适配器，不得出现在提示词、版本管理文件、成果或日志中。避免提供能导出密钥或私人数据的不受限 HTTP 工具。默认不选择云端追踪服务。

服务侧保留与 Telegram 消息删除，不等同于本地删除。不能将本地清理描述为已经保证擦除外部处理数据。实现接入时审查服务条款；本设计没有建立任何服务隐私保证。

## 可调保留默认值

| 类别 | 初始策略 |
| --- | --- |
| 原始对话归档 | 90 天 |
| 临时网页原始材料 | 30 天 |
| 详细执行和工具日志 | 30 天 |
| 个人记忆和有效任务约定 | 保留到用户删除、纠正或配置的过期时间 |
| 用户明确保存的成果 | 保留到用户删除 |
| 检查点 | 准确裁剪策略待定；移除旧历史时保留活跃线程可用的当前状态 |
| 备份与删除标记 | 准确保留时间和恢复机制待定 |

这些是 Kestri 本地副本的拟议默认值。M1 不自动裁剪记录、checkpoint 或成果，也不执行过期。明确保存成果所附的研究材料，需要有文档约定的转存和保留规则；保存成果不能悄然导致所有临时网页永久保留。存储正文过期后，来源 URL 可以继续作为元数据保留。

删除归档时必须处理检查点、摘要、索引、成果和缓存中的副本。活跃数据删除与备份过期是不同边界。恢复流程在启用执行或检索前，必须处理已删除任务和已忘记记忆。导出、备份、恢复和归档删除接口尚未确定。

## 限制与验证

对调用、运行时间、输出、并发与估算费用设置边界。新操作前检查限制，追踪仍可能完成或产生费用的在途工作。日志展示允许的操作、结果和策略拒绝，不暴露密钥。

容器、应用策略和备份处理不同失效场景，没有任何一项能建立绝对安全保证。验收证据必须覆盖正常流程与直接越界尝试，包括恶意网页指令、路径逃逸、私有网络请求、删除内容恢复、重启和发送不确定性。见[需求与验收案例](requirements.zh-CN.md)，尤其 AC-01、AC-07 和 AC-10 至 AC-12。
