# 对话式记忆管理

[English](memory-assistant.md) · [文档](../README.zh-CN.md)

更新：2026-10-02。状态：已实现；[运行证据](../development/memory-assistant-completion.zh-CN.md)单独记录。

## 交互约定

自然语言、命令与主人专属按钮共用记忆服务。支持查看记忆/设置、变化、候选、详情及真实回答诊断；明确切换自动提取/使用/语义检索；保存/纠正/遗忘；一次请求切换多个独立设置。明确直接请求立即执行，不重复确认。设置或目标模糊时只询问缺失信息。引用、条件、转发、外部和历史指令不能授权写入。短期目标选择绑定操作、替换内容和目标版本；数字回复与按钮执行前重新核验。模型不获得任意命令、配置项、凭据、预算或数据库访问能力。

有界结构化模型提案仅解释当前主人直接请求。应用验证允许操作与当前授权，提交控制并生成真实回执。状态修改在普通研究图之外完成，避免 epoch/上下文重置打断自身回执。模型说设置成功不是成功证据。只读导航可用确定性快捷路径。混合无关请求或缺少写入信息时澄清，不静默丢弃文本。

## 展示

记忆首页分别显示自动记录、回答使用、语义检索状态，有效记忆/候选数量和近期简短记录。只读按钮跳转分页、候选、变化和设置。详情优先显示内容、范围、本地时间和来源；技术字段放进详情/诊断。列表有界分页。无变化只用一句话；后台处理中/失败时显示有用状态，不重复空类别。用户内容转义后发送 Telegram HTML，控制回执使用明确展示类型，普通模型回答保持纯文本。一条消息包含多条命令时提示分开发送，不作变更。

## 真实诊断

记录每次实际模型调用的记忆注入 ID/版本、交流偏好/相关事实类别、检索方式与降级，不复制查询或事实正文。历史搜索实际发出的候选与完整读取另外记录。`/memory why [run ID]` 展示提供给模型的内容，不宣称内部推理或因果关系。只选择主人已完成的前台回答；旧回答没有记录时明确不可用。查看时重新检查当前同意、epoch、版本、范围、来源存在与有效状态，避免重新展示已撤销/删除/到期内容。沿用事件保留策略，逻辑恢复丢弃诊断/选择状态。诊断读取不调用提供方。
