## 配置与调度

| 变量 | 默认值 | 含义 |
| --- | --- | --- |
| `KESTRI_OWNER_TIMEZONE` | 未设置 | 显式 IANA 主人时区；否则每次创建需要提供时区 |
| `KESTRI_TASK_LIMIT` | 16 | 未删除任务上限，包括暂停任务；范围 1–64 |
| `KESTRI_BACKGROUND_QUEUE_LIMIT` | 8 | 排队/运行后台执行上限；范围 1–32 |
| `KESTRI_SCHEDULER_INTERVAL_SECONDS` | 5 | 本地到期检查间隔；范围 1–60 秒 |

一个前台 worker 与一个后台 worker 独立运行，共享 M1 调用、超时、输出、月度和单次执行费用边界。后台每次尝试的超时与前台研究相同。任务提案解析最多一次模型调用，使用相同计费准入。任务列表和斜杠控制通常不调用模型，需要理解的 `/task` 请求除外。

支持每日、每周本地墙上时钟时间，不支持任意 cron、间隔、单次提醒或月度规则。使用 `HH:MM`，或明确的中文时间如 `早上八点`。每周请求指定星期（内部周一=0，列表显示周一=1）。`tzdata` 提供跨平台 IANA 后备数据。夏令时不存在的本地时间跳过；重复时间只在较早的 fold 执行一次。时刻与执行唯一标识存为 UTC。创建、修改、恢复从下一个未来时刻开始；恢复不补跑暂停期间。

## 主人交互

| 输入 | 效果 |
| --- | --- |
| `每天 08:00 Asia/Shanghai 给我 AI 新闻简报` | 提议并持久化一项每日约定，回显 ID、内容、时间、时区、补跑规则和状态 |
| `每周一 08:00 Asia/Shanghai 给我 AI 新闻简报` | 每周约定 |
| `/tasks` | 不调用模型列出未删除任务约定 |
| `/task` | 显示任务输入指引 |
| `/task 暂停任务 TASK_ID` | 解析并暂停指定约定 |
| 回复约定/简报：`暂停` / `恢复` / `删除` | 通过消息关联目标任务 |
| 回复：`把这份简报改到 09:00` / `让这份简报更短一点` | 修改时间，或附加仅针对该任务的主人内容修订 |
| `/stop RUN_ID` | 通过无歧义、至少八字符的 UUID 前缀停止指定排队/运行执行 |
| 单独 `/stop` | 停止当前前台工作，不隐式停止后台执行 |
| `/new` | 没有前台排队/运行工作时清空前台提交上下文，保留任务和历史 |

只有一项任务时可解析省略的目标；存在多个候选时展示已签发选项，也可回复或提供任务 ID/名称。删除为 tombstone，任务从 `/tasks` 隐藏，记录/证据遵循[数据生命周期政策](data-lifecycle.zh-CN.md)。回复合并的 `/tasks` 列表不能指定其中一项。任务偏好不修改全局回答风格或个人记忆。

自然语言路由有意保守：识别中英文直接委托和控制表达；引用、转发、解释、条件示例不能授予任务权限。未识别表达仍按普通对话处理。缺少时间、时区或目标有歧义时使用有期限的待选操作，详见[对话式控制](assistant-controls.zh-CN.md)。显式时间、星期和指令摘录独立于模型检查。缺少时区、时间规则不支持、目标歧义或提案无效均不修改任务。

## 持久化与授权

PostgreSQL schema migration 2 加入约定、版本、任务变更记录、关联、执行种类、到期时刻、重试次数和可执行时刻。仍要求同数据库/机器人进程锁。调度器是本地异步循环，以 PostgreSQL 为调度事实来源，不引入独立消息队列或调度数据库。

任务提案 agent 只接收已授权主人的当前消息或经过验证的有限直接消息补充链，以及显式配置的时区。唯一结构化输出工具为 `TaskPlan`，没有研究或文件工具。提案本身不授予权限。应用检查直接请求与允许操作后，原子提交任务变更及按 run 标识的变更账本。重复更新、恢复已提交变更不会重复修改。取消到达时如果变更已提交，报告已保存约定，不虚称未修改。

研究 agent、来源材料、先前回答和定时执行没有任务管理工具。每次后台执行快照保存的指令、时区、约定版本和计划时刻，使用全新 graph 上下文，不推进前台 checkpoint。前台回复已完成简报可通过现有受限读取工具检查其结果证据。

## 停机、控制、重试与投递

默认每项任务六小时补跑窗口。多次错过仅合并为最新一次，最多补跑一次；过期则跳过并推进到下个未来时刻。容量满时保持到期工作可补跑，直到窗口过期。每项任务最多一项排队/运行执行。唯一 `(task_id, scheduled_for)` 约束阻止重复创建本地执行。过期排队执行在领取前取消，停机后可替换为最近一次仍有效的补跑。决策保留为操作事件。

暂停、修改、删除取消旧约定的排队执行；已开始的工作按快照继续。共享事务锁顺序串行化变更与定时启动。暂停回执后不再启动该任务的新定时工作。删除不撤回已提交外部请求，也不抹除历史；`/stop RUN_ID` 是独立取消操作。

指定暂时性模型/传输错误允许 30 秒后自动重试一次，共两次尝试。每次使用新的后台上下文；累计单次执行费用及未知预留仍受相同预算约束。暂停、删除、修改或过期的工作不重试。预算、策略、上下文和调用上限失败为终态。进程中断的执行报告一次，不盲目重跑。正常后台执行只发送最终简报，或一次最终失败/中断通知，不发送逐工具进度。

发送前提交结果和 outbox。已知未发送使用保存文本重试，最多三次发送尝试；不确定发送隔离为 `uncertain`。不保证远端恰好一次投递。`/status`、`/runs` 显示执行种类、证据/用量数量、安全错误及失败/不确定发送数量。M3 已提供范围个人记忆与压缩，见[记忆/上下文参考](memory-and-context.zh-CN.md)。M4 提供物理保留与保守恢复；导入任务需显式恢复。手动重发后续实现。应用必须在本地持续运行，电脑休眠或 Docker 停止会延迟工作。

当前控制增量：任务解析最多一次模型调用。多个目标可通过已签发的编号选项选择；缺少时间或时区时支持有期限的补充对话，不再要求每次重发完整请求。模型输入仅使用已验证的主人直接消息链。详见[对话式助理控制](assistant-controls.zh-CN.md)。
