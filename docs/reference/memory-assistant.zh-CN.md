# 对话式记忆操作

[English](memory-assistant.md) · [文档](../README.zh-CN.md)

更新：2026-10-02。自然语言控制与命令共用服务。

## 日常使用

可以说“帮我开启自动记忆和语义检索”“回答时先不要使用我的记忆”“你现在记住了我哪些事情”“最近记住了什么”或“查看待确认记忆”。明确请求直接执行；设置含糊时澄清。自动记录、回答使用和语义召回独立控制。自动记录将之后的直接聊天发送到 DeepSeek；语义召回将合格事实、历史和查询发送到北京 DashScope，沿用同意和预算限制。

保存、纠正和忘记时指出对应事实。目标不唯一时最多列出五条；十分钟内回复“第二条”或点击按钮。选择支持进程重启，但设置/代次变化、目标版本变化或超时后失效，执行后只能消费一次。普通聊天不会选择目标。

## 查看与导航

首页分别展示开关、数量和近期事实。只读按钮打开列表、待确认、变化和设置。列表每页五条，详情显示记录方式、主人本地时间和来源归档。仍可使用 `/memory list`、`/memory pending`、`/memory changes`、`/memory settings` 和 `/memory inspect ID`。每条命令单独发送。控制回执使用转义 HTML，普通回答保持纯文本。按钮仅接受已配置主人的私聊。

## 回答依据

询问“为什么刚才这样回答”或点击“记忆依据”。`/memory why [run ID]` 展示成功模型调用实际收到的记忆编号/版本、检索方式/降级，以及分别观察到的历史搜索和完整读取编号。它不展示内部推理，也不证明因果关系。旧回答没有记录时明确不可用。查看时重新检查同意、代次、当前版本、范围、来源和有效期；撤销事实不会重新显示。只读查看和诊断不调用提供方。

## 实现与恢复

`management.py` 识别当前主人直接请求，对非简单控制最多发起一次有界结构化提案。应用验证后由共享事务服务写入；模型没有 shell、任意配置或 SQL 工具。只读导航走确定性路径。展示元数据只保存按钮/代次，不复制正文；诊断事件只保存标识，不保存事实或查询。

迁移 10 增加 `conversations.memory_choice` 和 `outbox.presentation`。逻辑备份 schema 8 兼容旧 schema 4–7；恢复清空选择、展示和注入/历史诊断事件，保留既有隔离与同意规则。向量仍为可重建索引。升级时使用两个 Compose 文件并保留迁移前私有快照。

参见[设计](../design/memory-assistant.zh-CN.md)。Telegram 接入依据官方 [Bot API](https://core.telegram.org/bots/api)。
