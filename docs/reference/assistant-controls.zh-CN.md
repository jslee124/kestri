# 对话式助理控制

[English](assistant-controls.md) · [文档导航](../README.zh-CN.md)

更新：2026-10-03。这里描述已实现的接口；部署证据单独记录。

## 日常控制

| 自然表达或命令 | 结果 |
| --- | --- |
| `我有哪些任务？` / `/tasks` | 每页五项，提供详情和下一页按钮 |
| `你现在在做什么？` / `/status` | 当前排队或执行中的工作 |
| `查看最近执行记录` / `/runs` | 最近五次执行；`/runs inspect ID` 查看唯一匹配的执行 |
| `本月花费` / `/usage` | UTC 月内本地美元估算和预留额度 |
| `停止当前执行` / `/stop` | 停止前台执行；暂停持续任务是另一项操作 |
| `开始新话题` / `/new` | 前台空闲时重置已提交上下文和待选操作 |
| `你能做什么？` / `/help` | 使用示例和只读导航 |

这些查询走确定性路由，不调用模型。自然表达的识别范围有限，并非承诺理解任意句子。已有的[记忆控制](memory-assistant.zh-CN.md)使用同一入口，并保留自己的策略检查。

## 任务对话

创建每日或每周任务时提供时间、内容和 IANA 时区；配置了 `KESTRI_OWNER_TIMEZONE` 时可以省略时区。例如：`每天早上八点 Asia/Shanghai 给我 AI 新闻简报`。任务解析最多调用一次模型，只提供结构化 `TaskPlan`，没有研究、shell 或配置工具。写入前由应用检查操作权限，以及时间、内容是否确实来自主人请求。

目标有歧义时，展示最多五个编号选项。点击按钮或回复 `第二个`，待执行操作仅应用于选中版本。缺少时间或时区时，可以补充 `晚上八点` 或 `Asia/Shanghai`。补充链最多包含三条归档的主人直接控制消息，十分钟内有效。普通聊天不能补齐任务字段。成功修改后，十分钟内可以用 `改到晚上九点` 明确继续修改同一版本的时间；普通对话会清除此引用。单独的时间不会修改已经完成的任务约定。

重启保留待选操作。目标版本变化、选项过期、来源消息缺失或过期、新话题、记忆 epoch 变化和保守恢复均会撤销权限。任务与记忆共用一个持久化待选槽位，通过领域标记区分；新待选操作可能替换旧操作。无效或过期选择不会产生变更。重复更新和恢复已提交操作时，返回持久化的实际变更回执。

## 输出与边界

任务摘要展示标题、中文状态、本地时间、时区和短编号；详情展示内容、补跑规则和下次计划。状态与历史展示执行类型、时间、证据及调用次数、发送问题。控制消息使用转义后的 Telegram HTML 和只读导航；普通成功回答仍使用纯文本。选择按钮携带已签发的操作 token，不承载任意指令。按钮不会直接切换设置或删除任务。

只有经过身份验证的主人私聊直接消息才能授权写入。转发、引用、否定和假设内容不能授权任务操作；不兼容的混合操作会要求分别发送。应用授权检查优先于模型提案。暂停任务阻止后续启动；停止已经开始的执行需要 `/stop ID`。本地用量不等于提供方账单。执行及恢复边界见[任务调度](tasks.zh-CN.md)。
