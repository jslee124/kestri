# Kestri 第一版位图素材

[English](kestri-assets-v1.md)

此文件保留正式矢量制作之前的位图导出记录。正式使用请查看[视觉规范](README.zh-CN.md)。

## 文件

- `kestri-mascot-v1.png`：1225 × 1284 的透明背景全身吉祥物。
- `kestri-telegram-avatar-v1.png`：1254 × 1254 的暖白底方形头像，早于正式矢量头像。
- `preview.html`：目前展示正式矢量素材的深浅背景与不同尺寸圆形头像。

这些素材基于已选定的 `kestri-concept-v1.png`，使用内置 `image_gen` 生成。
它们是位图素材，不是 SVG 母版。此次生成没有更新 Telegram 头像。

## 吉祥物提示词

用途：背景提取。输入为已选定的 Kestri 品牌设计板，作为编辑目标。
只提取设计板左侧的大型全身红隼，输出独立透明 PNG。忠实保留歪头、朝右的
三分之四视角、赭橙色头部和收拢翅膀、奶油色胸口、带小白色高光的深墨色椭圆
眼睛、脸颊深色纵纹、灰蓝色弯喙、分层灰蓝翼形、深色末端的长尾与金黄色小脚。

保留左侧主角色的比例、表情、柔和而干净的平面形状和颜色，不重新设计角色，
也不使用下面的小动作样本。整只鸟、双脚和尾羽都必须完整可见，居中放置，
四周约留 8% 的透明空白。鸟外部是真正的透明通道，不将棋盘格画进图像；
没有背景、地面阴影、方块底、字标、色块、文字或额外物体。边缘干净，适合 README 和网站。

## 头像提示词

用途：对象精确编辑。输入为已选定设计板，作为角色参考与编辑目标。
只输出独立方形 Telegram 头像，忠实沿用右上角彩色头部图标。保留赭橙色头部、
奶油色脸部和胸口、带小白色高光的深墨色椭圆眼睛、脸颊深色纵纹、灰蓝和金黄色
弯喙、轻微歪头以及朝右的三分之四视角。风格保持简洁，不添加羽毛纹理和新细节。

画布为一比一方形，以纯暖象牙白铺满背景，内部没有圆角方块、边框和文字。
头部和上胸居中，头顶完整，顶部、左右约留 18% 空白。眼睛、喙和脸颊纹应在中心
圆形安全范围内，圆形裁切保留完整头部与脸颊。下胸可以靠近底部，面部在 32 像素
下仍能识别。不添加字标、全身角色、双脚、色块、阴影和展示模型。输出为不透明底方形头像。
